# 标注工具、标准答案与精准反馈验收

日期：2026-09-13。实际服务：`http://127.0.0.1:8000`。

## 本次行为

- 矩形编辑采用现有平台兼容方案。画框与选择工具分开，每个对象都有独立标签；对象列表可以选择被遮住的重叠框，四边与四角均可拖动。取消拖动不保存半成品，每次完整操作可撤销。
- 已核对 [Label Studio 官方前端说明](https://labelstud.io/guide/frontend)：独立前端发行从 1.11.0 起弃用。本次没有把教学平台宣称为 CVAT 或 Label Studio，也没有引入旧前端发行包。
- 课关、岗位分步实操、新手独立标注及错题复习中的标注题，答对或同题连续答错至少 3 次后，可主动点击“查看标准答案”。服务端校验资格，答案查询不新增作答、分数或错误次数。活动中的岗关和赛关仍在整包结算后公布结果。
- 查看标准答案时显示真实参考框或轮廓，并禁用绘制、移动、边界调整、标签、删除、撤销和键盘修改。允许缩放查看图片。点击“再试一次”清除用户标注、标准答案和本轮编辑历史，恢复空白作答。
- 页面刷新恢复已提交标注、反馈与连续错误次数；不会自动加载标准框。错题复习计数单独存储在 `mistakes.review_wrong_attempts`，启动时以显式 `ALTER TABLE ... ADD COLUMN IF NOT EXISTS` 兼容已有数据库。
- IoU 严格超过 90% 时，播放白色圆底绿色对钩 Lottie，无黄色矩形和彩纸；专用语音是新下载的 Kenney CC0 真人男声“Congratulations!”，与普通 Kokoro 女声分开。来源、许可和校验值见 [voice-feedback.md](voice-feedback.md)。

## 实际浏览器与数据库观察

使用本轮独立账号 `qa_agent_annotation_0913`，没有向演示账号提交测试答案。训练题直接复制当前发布题集的题目快照，没有改写正式题目或标准答案。

1. 在同一图片里绘制两个重叠框，分别指定“狗”和“行人”；从对象列表选择第一框，向上拖动上边界。读取实际 SVG 坐标确认第二框四个坐标均未改变，第一框只改变上边界与高度。
2. 通过页面真实提交三次错误。第一次、第二次没有查看入口；第三次出现“查看标准答案”。刷新后仍恢复同题与查看资格。
3. 主动查看后，SVG 参考框为 `[0.43836448598130846, 0.199875, 0.2749065420560747, 0.44921875]`，与该题后端快照一致，标签为“行人”。控制柄数量为 0，标签控件禁用；实际拖动和按 Delete 后作答框与标准框数量均不变。
4. 点击“再试一次”，作答框与标准框数量均变为 0；重新绘制并提交得到 99.6% IoU，页面正确判定，截图看到白色圆底绿色对钩，页面返回“精准反馈语音已播放”。这证明播放调用返回成功，不将其描述为人工主观试听。
5. PostgreSQL 核对正式提交计数为 4、答对计数为 1、连续错误归零；最终答案含实际绘制的归一化坐标。查看答案与重试本身没有新增计分。
6. 错题本三次复习由真实 HTTP API 保存，第一、二次资格为 false，第三次为 true；浏览器打开后恢复资格，点击查看显示 1 个标准框与禁用标签。再次点击重试后作答框和标准框均清零。
7. 最终页面未发现控制台错误。浏览器实际检查覆盖桌面矩形题与错题本；多边形、新手恢复与其余八向细节分别由组件/API检查提供证据，没有宣称这些分支均已完整浏览器操作。
