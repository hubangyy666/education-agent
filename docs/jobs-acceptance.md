# 岗位固定讲解版验收

日期：2026-09-11。目录版本 `2026-09-11-fixed-v2`。服务 `http://127.0.0.1:8000`。

## 本版行为

- 任务页右上角、全局菜单、首页与岗位页均移除企业任务转换入口。历史转换工具及历史数据保留，岗位模块不引用其接口。
- 四个岗位采用 Brilliant 参考图的白底、分组标题、浅灰横向路径、方形插图块与下置标题；蓝、橙、紫、绿区分方向。
- 八项固定任务直接打开详情，不选择学习目标，不生成或展示“学习型任务卡”。
- 工作情境、任务描述、交付物、真实样图、32 个操作步骤及 64 段详细解释、操作规范、质量要求、考核方式与关联知识技能齐全。
- 四步讲解可自由切换阅读；学习记录和真实训练按顺序保存，点击阅读不计为实操完成。
- 旧学习地址跳转到相应固定任务；已有学习记录保留，生成过的旧文字不覆盖固定正文。

- 独立重启的服务完成八任务读取与全部图片响应验证；只读不创建记录，保存与数据库往返一致，重复请求恢复同一记录。`jobs-fixed-live-evidence.json`。脚本不调用模型，临时账号已删除。

## 来源和范围

COCO 与 KolektorSDD 图像沿用原始许可。新增三张 Label Studio 官方工作界面截图，原图未修改，保留 Apache-2.0 许可文件。每项任务均有图片性质、来源与中文说明；文本为虚构教学语料。固定讲解是教学编写，不冒充企业内部工单。

目录内较早的 `jobs-live-evidence.json`、`jobs-browser-evidence.json`、`jobs-tests.xml`、`jobs-export-example.md` 仅记录本版之前的生成式实现，不作为本次固定讲解版的验收依据。本版以带 `fixed` 的证据文件及本说明为准。
