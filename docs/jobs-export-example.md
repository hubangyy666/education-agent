## 对应知识点

### 负样本的作用

无缺陷图像为正常外观提供参照；保留负样本有助于发现把正常纹理当异常的倾向。

对应技能：A6 / A6-S4

来源：KSDD

### 分类与定位

是否有缺陷是图像级判断，缺陷在哪里是区域判断，两种交付物不能互相替代。

对应技能：A1 / A1-S2

来源：KSDD、CVAT-BOX
